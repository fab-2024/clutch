# Avatars joueur

- `clutch-avatars-free-15.png` est la planche active de 15 avatars de l’application actuelle.
- La planche contient uniquement les portraits utilisés par le catalogue courant.

## Prompt de production

Reconstituer une planche propre de 5 colonnes par 3 lignes avec les 15 avatars de la référence, dans le même ordre. Centrer chaque sujet dans une tuile carrée uniforme sur fond bleu nuit presque noir. Retirer uniquement les numéros, bordures colorées, marges de page et légende. Préserver les silhouettes, cadrages, poses, palettes et éclairages. Aucun texte, numéro, logo, marque, filigrane, sujet ajouté ou sujet manquant.
